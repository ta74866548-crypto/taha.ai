# 🤖 AI Lesson Summarizer (مُلخص الدروس الذكي)

منصة ويب متكاملة تتيح للطلاب والمعلمين رفع دروسهم (ملفات PDF) واستخدام الذكاء الاصطناعي (Google Gemini) لتوليد ملخصات دقيقة، وإنشاء أسئلة للمراجعة، والدردشة مع الذكاء الاصطناعي حول محتوى الدرس.

## 📁 هيكل المشروع (Project Structure)

المشروع مفصول بالكامل إلى أجزاء لتسهيل التطوير والرفع على GitHub:

- **`frontend/`**: يحتوي على واجهة المستخدم (HTML, CSS, JS) وهو مفصول تماماً عن الباك-إند (يتواصل معه عبر API).
- **`backend/`**: سيرفر مبني باستخدام Python و Flask.
  - **`app.py`**: السيرفر الأساسي وموجه الروابط (Routes).
  - **`ai/`**: مجلد معزول يحتوي على منطق الذكاء الاصطناعي (التلخيص، الأسئلة، الشات).
  - **`utils/`**: مجلد الأدوات المساعدة مثل قراءة ملفات الـ PDF.
- **`uploads/`**: مجلد لحفظ الملفات المرفوعة مؤقتاً (مستثنى من جيت هاب).
- **`database/`**: مجلد لحفظ قاعدة البيانات (مستثنى من جيت هاب).

## 🚀 طريقة التشغيل (Getting Started)

### 1. إعداد الباك-إند (Backend Setup)
تأكد من تثبيت Python، ثم قم بتنفيذ الأوامر التالية:

```bash
# تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# تشغيل السيرفر
cd backend
python app.py
```
سيعمل السيرفر على الرابط `http://127.0.0.1:5000`

### 2. تشغيل الواجهة (Frontend Setup)
ببساطة، قم بفتح ملف `frontend/index.html` في أي متصفح، أو استخدم إضافة (Live Server) في VSCode لتجربة أفضل.

## 🛠️ التقنيات المستخدمة
- **الواجهة (Frontend)**: HTML5, CSS3, Vanilla JavaScript (Fetch API)
- **الخادم (Backend)**: Python, Flask, Flask-CORS, PyPDF2
- **الذكاء الاصطناعي (AI)**: Google Generative AI (Gemini 1.5 Flash)
